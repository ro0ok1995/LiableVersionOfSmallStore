# إصلاحات شاشة الحسابات — SmallStore 16

## نطاق التعديل
- مصدر رصيد العميل في بطاقات الحسابات والترتيب هو `CustomerLedgerCalculator` بدل الحقل القديم `CustomerAccount.balance`.
- فلاتر الموردين لا تعتبر الرصيد غير المتاح صفرًا ولا تضع المورد تلقائيًا في «خالص الحساب» عند فشل جلب الرصيد.
- عند تعذر تحميل رصيد مورد، تظهر حالة «تعذر تحميل الرصيد» بدل مبلغ أو حالة تسوية غير موثوقة.
- تمييز القائمة الفارغة فعليًا عن عدم وجود نتائج للبحث أو التصفية، مع خيار لمسح البحث والتصفية.
- زر إضافة العميل ينقل إلى إدارة العملاء عبر مسار مركز البيانات، ويفتح نافذة الإضافة تلقائيًا.
- زر إضافة المورد ينقل إلى إدارة الموردين عبر مسار مركز البيانات، ويفتح نافذة الإضافة تلقائيًا.
- إلغاء الإضافة يغلق النافذة ويبقي المستخدم في صفحة إدارة السجلات. عند الإضافة الناجحة من المسار الذي بدأ من الحسابات، يعود التطبيق إلى شاشة الحسابات مع الحفاظ على تبويب العملاء أو الموردين.
- إزالة مسار الإضافة المحلي الاحتياطي للمورد من شاشة الحسابات.
- لم يُعد تصميم شاشة الحسابات أو تغيير تخطيطها أو ألوانها عمدًا.

## التحقق
تمت مراجعة التغييرات نصيًا. تعذر تشغيل `assembleDebug` في بيئة العمل لأن Gradle Wrapper يحتاج تنزيل Gradle من `services.gradle.org` والاتصال بالشبكة غير متاح. لذلك يجب تشغيل بناء GitHub Actions أو Android Studio قبل اعتماد النسخة النهائية، ثم اختبار حالات الإضافة والإلغاء والأرصدة.
