# ملاحظات نسخة الاختبار التجريبية — SmallStore

## الملفات
- `demo-data/SmallStore_Demo_Backup_v6_Complete_Accounting_Test_Data.json`: نسخة JSON بصيغة النسخ الاحتياطي v2 التي يتعامل معها `BackupManager` في هذا المشروع.

## محتويات البيانات
- 10 عملاء، 5 موردين، 20 منتجًا موزعة على 10 فئات منتجات.
- 5 حسابات مالية: `acc_cash`, `acc_bank_palestine`, `acc_palpay`, `acc_jawwalpay`, `acc_maltachat`.
- 5 طرق دفع مطابقة: `pm_cash`, `pm_bank_palestine`, `pm_palpay`, `pm_jawwalpay`, `pm_maltachat`.
- فواتير شراء نقدية وآجلة وجزئية، دفعات للموردين، ومرتجع شراء.
- مبيعات نقدية وآجلة ومختلطة، قبض دفعات عملاء، مرتجع مبيعات ورد نقدي.
- 5 فئات مصروفات ومصروفات مدفوعة من الحسابات المالية الخمسة.
- أرصدة افتتاحية لعملاء وموردين، وحركات مخزون مرتبطة بفواتير الشراء والبيع والمرتجعات.
- التواريخ التشغيلية بين 2026-10-20 و2026-10-28.

## رأس المال
لم تتم إضافة سجل رأس مال مصطنع. صيغة `BackupPayload` الحالية لا تحتوي كيانًا أو حقلًا مستقلًا لرأس المال يمكن تأكيد استعادته؛ لذلك تُرك خارج الملف بدل إضافة بيانات يتجاهلها التطبيق.

## تحذير مهم
استعادة نسخة احتياطية في هذا التطبيق تستبدل البيانات الحالية داخل قاعدة البيانات ضمن معاملة واحدة. استخدم الملف في قاعدة اختبار فارغة أو صدّر نسخة احتياطية من بياناتك الحقيقية قبل استيراده. هذا الملف يحتوي بيانات تجريبية وليست بيانات حقيقية.

## التحقق
تم التحقق آليًا من JSON ومن عدد السجلات، وربط المعرّفات، وتطابق مبالغ فواتير الشراء والبيع مع مجموع السطور، وتطابق إجمالي كل فاتورة مع `paidAmount + creditAmount`. لم يمكن تشغيل Gradle في بيئة إعداد الملف لأن توزيع Gradle 9.3.1 غير موجود محليًا والبيئة لا تستطيع الوصول إلى `services.gradle.org`؛ لذلك يجب تشغيل build والاختبارات في GitHub Actions أو Android Studio قبل اعتماد النسخة للإنتاج.
