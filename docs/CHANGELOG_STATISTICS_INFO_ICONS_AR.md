# تحديث أيقونات شرح بطاقات الإحصائيات

## التعديل
- استُخدمت أيقونة المعلومات الدائرية `Info` باللون البنفسجي بدل علامة التعجب النصية داخل بطاقات مؤشرات الإحصائيات، لتطابق الشكل المرجعي المرفق.
- بقي مثلث التحذير الأحمر منفصلًا لتمييز البطاقات التي تحتوي على بيانات تكلفة ناقصة.
- حسّنت نافذة الشرح لتعرض تعريفًا أوضح وصيغة حساب ومثالًا عند الحاجة، مع توضيح استبعاد العمليات الملغاة/المعكوسة والتمييز بين حركة الفترة والرصيد الحالي.
- أُضيف استيراد `getValue` و`setValue` المطلوبين لتعريف حالات Compose باستخدام `by` في هذا الملف.

## النطاق
التعديل في `StatisticsTabContent.kt` فقط، إضافة إلى هذا الملف التوثيقي. لم تُغيّر قواعد الحساب أو قاعدة البيانات.

## التحقق
لم يُؤكّد نجاح بناء Android في هذه البيئة؛ يجب تشغيل GitHub Actions بعد رفع النسخة للتحقق من الترجمة.
